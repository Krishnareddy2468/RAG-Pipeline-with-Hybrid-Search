Internal API Reference

Owner: API Platform Team

Last updated: 2026-07-28

POST /v1/customers

Creates a new customer record. The request must include email, name, and plan_id.

Returns status code 201 when the customer is created successfully.

GET /v1/customers/{customer_id}

Returns customer profile details for the provided customer ID.

If the customer does not exist, the API returns CUST_404_NOT_FOUND.

Rate Limits

Authenticated clients can make 600 requests per minute. If the limit is exceeded, the API returns AUTH_429_RATE_LIMIT.

Idempotency

Write endpoints support the Idempotency-Key header. Clients should reuse the same key when retrying a failed create request.

Internal use only.
